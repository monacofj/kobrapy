KobraPy — Programming Exercise
==============================

KobraPy is a programming exercise inspired by the classic snake game of the
1980s. Written in Python, it offers a small, functional codebase that students
can explore, modify, and extend.

Originally developed to introduce undergraduate computer science students to
open-source development practices and software project management, KobraPy
can also be used in other educational settings or for independent study.

The exercise aims to help students:

- Understand the principles and practices of open-source software development.
- Gain hands-on experience with version control and project management tools.
- Develop skills in collaborative development and project coordination.

To this end, KobraPy provides a starter codebase alongside known bugs, feature
requests, and suggested improvements. Students use these as a basis for setting
up their own repositories, managing issues, submitting pull requests, discussing
changes, and coordinating releases.
