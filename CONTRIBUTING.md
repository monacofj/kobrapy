Contributing to KobraPy
=======================

Contributions to KobraPy are welcome! Whether you want to fix a bug, suggest a
feature, or improve the documentation, your help is appreciated.

Getting Started
---------------

Before contributing, please read the [README](README.md) and the
[user manual](docs/manual.md) to familiarize yourself with the project.

If you are using KobraPy for a programming exercise, follow the
[exercise instructions](docs/exercise.md) instead. The exercise involves
creating your own project, rather than contributing directly to KobraPy.

Contribution Workflow
---------------------

1. Open an issue describing the problem or proposed improvement, or choose
   an existing issue.
2. Fork the repository and create a branch for your changes.
3. Make your changes, following the conventions below.
4. Submit a pull request referencing the corresponding issue.
5. Participate in the review and discussion of your contribution.

Please keep contributions focused and reasonably small to facilitate review.

Conventions
-----------

- Write code, comments, and documentation in English.
- Follow [PEP 8](https://peps.python.org/pep-0008/) coding conventions.
- Keep documentation consistent with your changes.
- Preserve existing copyright notices and follow the project's GPL licensing
  terms.

Code of Conduct
---------------

All contributors are expected to follow our
[Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping improve KobraPy!
