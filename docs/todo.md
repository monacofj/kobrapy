To-Do List
==========

Read [the programming exercise](exercise.md) before starting. In your own
project, complete the following steps:

1. **Add project maintainers.** Invite the team members who will maintain
   the project and give them appropriate repository access.
2. **Configure the repository.** Set up the repository for collaborative
   development and issue tracking.
3. **Populate the issue tracker.** Create issues in your own repository
   using the [issue catalog](issues.md). Some issues depend on others;
   consider these dependencies when planning the work.
4. **Resolve mandatory issues.** Complete at least all **Critical** and
   **Required** issues.
5. **Implement optional improvements.** Choose and resolve **Wish** issues
   when appropriate.
6. **Plan and publish releases.** Organize the work into milestones,
   prepare the planned versions, and publish your releases.

Follow the contribution and release workflow described in
[the programming exercise](exercise.md).
